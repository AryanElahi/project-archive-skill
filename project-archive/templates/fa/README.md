# <اسم پروژه>

این پوشه مرجع همه‌ی کارهای <پروژه> است.
قاعده: هر فایل، برنامه، تصمیم و خلاصه‌ی گفت‌وگو از این به بعد هم اینجا ذخیره می‌شود.

## شروع سریع
اول `00-از-اینجا-شروع-کن.md` را بخوان؛ وضعیت کار، قوانین ثابت و قدم بعدی آنجاست.

## ساختار
- `01-<منبع-حقیقت>/` — <سند مادر، تاریخ‌دار>
- `02-منابع/` — آنچه قبل از تغییر خوانده شد (وضعیت «قبل»)
- `03-برنامه‌ها/` — برنامه‌ی کارهای بعدی
- `04-گفت‌وگوها/` — گزارش هر جلسه: پیام‌ها، پاسخ‌ها و تصمیم‌ها
- `05-…/` — <خروجی‌ها: متن ذخیره‌شده‌ی هر بخش و نسخه‌های پشتیبان>
